# API changes from 0.25.0 to 0.26.0-beta1: full list

This is the appendix to [the upgrade guide](upgrade-0.26.0-beta1.md). Start with the
"Breaking API changes" section there; it has the calls an integration built on the
0.25.0 kit is most likely to use. This list has every change found by comparing the
0.25.0 and 0.26.0-beta1 OpenAPI documents of the APIs that the gateway of the kit
exposes. "(+N more operations)" means the same change applies to N more calls of the
same API.

Authentication, scopes, success status codes and content types did not change for any
call. The DID API and the tenant KMS API have no breaking change.

## Not reachable on 0.25.0

The modeling (`/api/modeling/v1`) and organization (`/api/organization/v1`) APIs were not
exposed by the 0.25.0 gateway of the kit, so a 0.25.0 integration cannot depend on them.
Their action paths changed from `:verb` to `/verb` as well (3 groups of calls).
